## 4. Preguntas para el planner

1. **¿El aviso de dependencias no verificadas debe llegar a `Confianza.avisos`?** Decisión: no llega. Sale como hallazgo de severidad 1 en Entrega y como aviso del Gate. `Confianza.avisos` sale de `v.avisos` en `src/oracle/mod.rs`, que está fuera de mi lista. Para llegar hay que sumar el texto a esa lista en `mod.rs`.
2. **¿El detalle debe empezar con el texto fijo?** Decisión: no. El detalle es "clon sin metadatos estáticos: dependencias de runtime no verificadas: <url>". Para el sdist es "sdist con metadatos anteriores a 2.1: dependencias de runtime no verificadas: <nombre>". Contiene el texto fijo, pero no empieza con él.
3. **¿El Gate del rechazo de fuentes debe llevar un motivo?** Decisión: lleva solo archivo y línea. Algunos motivos del inventario traen valores del repo, como una URL o una ruta. El Gate de inventario que ya existía sigue escribiendo la cita redactada.
4. **¿Un error de compilación de una dependencia de runtime debe dar `no-instala`?** Decisión: no lo cambié. Hoy un stderr sin patrón conocido, como `error: command 'gcc' failed`, da `Infra`. Cambiarlo es decidir en `diagnosticar`.
5. **¿Una caché de Python sin `metadata-vieja-sdist.json` deja de ser acierto?** Decisión: sí. `requisitos_sdist_listos` exige el tercer JSON. La descarga se repite una vez por caché con sdists.
6. **¿Quitamos `cache_de`?** Decisión: queda, para no ampliar el alcance.
