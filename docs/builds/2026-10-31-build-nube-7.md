### Qué hace la Tarea 35

- **Carpeta.** El script calcula la ruta del repo desde su propia ubicación, con `pwd -P`.
- **Carpeta.** El hash corto son los primeros 12 caracteres de `sha256sum` de esa ruta.
- **Carpeta.** `target`, `tmp` y `home.XXXXXX` van bajo `~/.cache/root-tests/<hash>/`.
- **Carpeta.** `CARGO_TARGET_DIR_SEGURO` sigue ganando sobre esa carpeta.
- **Lock.** Sin `ROOT_SIN_PODMAN=1`, el script abre `~/.cache/root-tests/podman.lock` y espera con `flock`.
- **Lock.** Si el lock está tomado, el script avisa una línea en stderr antes de esperar.
- **Lock.** Con `ROOT_SIN_PODMAN=1`, el script no crea el archivo del lock y no espera.
- **Lock.** El criterio es el de `src/entorno.rs`: solo el valor exacto `1` saltea.
- **Lock.** Cargo corre con el descriptor del lock cerrado. El script retiene el lock hasta que cargo termina.
